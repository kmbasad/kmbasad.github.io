| বাংলা | ফারসি | # |
| :-- | :-- | --: |
| চোখের মিনারের এই বারান্দা আশিয়ানা তোমার, | رَواقِ منظرِ چشمِ من آشیانهٔ توست | 34 |
| দয়া করো, নেমে আসো, এই ঘরই তো ঠিকানা তোমার। | کَرَم نما و فرود آ که خانه، خانهٔ توست |  |
| তিল আর রেখার লাবণ্যে আরিফদের দিল নিলে, | به لطفِ خال و خط از عارفان ربودی دل |  |
| আজব সব রহস্য-ঢাকা ফাঁদ আর দানা তোমার। | لطیفه‌های عَجَب زیرِ دام و دانهٔ توست |  |
| গোলাপের মিলনে খুশি থাক দিল, ভোরের বুলবুল, | دلت به وصلِ گل ای بلبلِ صبا خوش باد |  |
| বাগান জুড়ে যত গান, সে সবই আশিকানা তোমার। | که در چمن همه گلبانگِ عاشقانهٔ توست |  |
| আমাদের দুর্বল দিলের ইলাজ ঠোঁটে সঁপে দাও, | عِلاجِ ضعفِ دلِ ما به لب حوالت کن |  |
| কারণ চুনি-গলা এই শরবতের খাজানা তোমার। | که این مُفَرّح یاقوت در خزانهٔ توست |  |
| শরীরে পারিনি পেতে তোমার খিদমতের দৌলত, | به تن مُقصرم از دولتِ ملازمتت |  |
| তবু আমার জান ধুলা হয়ে ছোঁয় আস্তানা তোমার। | ولی خلاصهٔ جان، خاکِ آستانهٔ توست |  |
| আমি সে নই যে দিলের নগদ দেব যে-কোনো চটুলে, | من آن نیَم که دَهَم نقدِ دل به هر شوخی |  |
| খাজানার দুয়ারে সিল তোমার আর নিশানা তোমার। | دَرِ خزانه، به مُهر تو و نشانهٔ توست |  |
| কি আজব পুতুল তুমি, মধুর-কাজের শাহসওয়ার, | تو خود چه لعبتی ای شهسوارِ شیرین کار |  |
| আকাশের মতো বুনো ঘোড়া চাবুকে পোষমানা তোমার। | که توسَنی چو فلک، رامِ تازیانهٔ توست |  |
| আমি কোন ছার, ভেলকিবাজ আকাশই পিছলে পড়ে | چه جای من، که بِلَغزَد سپهرِ شعبده‌باز |  |
| এসব ছল-চাতুরিতে, যা থলি-ভরা বাহানা তোমার। | از این حیَل که در انبانهٔ بهانهٔ توست |  |
| তোমার মজলিসের গানে আকাশ এখন নেচে ওঠে, | سرودِ مجلست اکنون فلک به رقص آرَد |  |
| কারণ মিঠে-কথার হাফিজের শের তারানা তোমার। | که شعرِ حافظِ شیرین سخن ترانهٔ توست |  |
| | | |
| যাও নিজের কাজে, ওহে ওয়ায়েজ, এ কেমন ফরিয়াদ? | برو به کارِ خود ای واعظ این چه فریادست؟ | 35 |
| আমার দিল পথ হারাল, তোমার আবার কি প্রমাদ? | مرا فِتاد دل از ره، تو را چه اُفتادست؟ |  |
| তার ওই কোমর, যা খোদা বানিয়েছেন শূন্য থেকে, | میان او که خدا آفریده است از هیچ |  |
| এমন সূক্ষ্ম ধাঁধা, কেউ খোলেনি খোদার সে ইজাদ। | دقیقه‌ای‌ست که هیچ آفریده نَگشادست |  |
| যতক্ষণ না তার ঠোঁট মেটায় সাধ, বাঁশির মতো | به کام تا نرساند مرا لبش، چون نای |  |
| সারা জাহানের নসিহত আমার কানে তো বরবাদ। | نصیحتِ همه عالم به گوشِ من بادست |  |
| তোমার গলির ফকির আট বেহেশ্তেও বেপরোয়া, | گدایِ کویِ تو از هشت خُلد، مستغنی‌ست |  |
| তোমার প্রেমের বন্দি দুই জাহান থেকেই আজাদ। | اسیرِ عشقِ تو از هر دو عالم آزادست |  |
| যদিও প্রেমের নেশা আমাকে করেছে খারাব, তবুও | اگر چه مستیِ عشقم خراب کرد ولی |  |
| আমার অস্তিত্বের ভিত সেই খারাবিতে আবাদ। | اساسِ هستیِ من زآن خراب، آبادست |  |
| ও দিল, ইয়ারের জুলুম অবিচারে কেঁদো না, ইয়ার | دلا مَنال ز بیداد و جورِ یار که یار |  |
| এটাই দিল তোমার নসিবে, আর এ তারই প্রসাদ। | تو را نصیب همین کرد و این از آن دادست |  |
| যাও হে হাফিজ, কিসসা পড়ো না, ফুঁকো না মন্ত্র-জাদু, | برو فَسانه مخوان و فُسون مدم حافظ |  |
| কারণ এমন কিসসা আর জাদু ঢের আছে ইয়াদ। | کز این فسانه و افسون مرا بسی یادست |  |
| | | |
| তোমার চুলের ডগা যখন নসিমের হাতে পড়েছে, | تا سرِ زلفِ تو در دستِ نسیم افتادست | 36 |
| পাগল দিল দুঃখে দু-টুকরো হয়ে মাটিতে পড়েছে। | دلِ سودازده از غُصه دو نیم افتادست |  |
| তোমার জাদু-চোখ তো নিজেই জাদুর আসল খসড়া, | چَشمِ جادویِ تو خود عینِ سَوادِ سِحْر است |  |
| তবু কথা এই যে, এ নুসখা রোগের দশাতে পড়েছে। | لیکن این هست که این نُسخه سَقیم اُفتادست |  |
| তোমার চুলের প্যাঁচে ওই কালো তিলটা, জানো কি সেটা? | در خَمِ زلف تو آن خالِ سیه دانی چیست؟ |  |
| কালির ফোঁটা, যা ওই জিম হরফের বাঁকেতে পড়েছে। | نقطهٔ دوده که در حلقه جیم افتادست |  |
| ফেরদৌস-গালের বাগে তোমার মেশক-কালো চুল | زلفِ مشکینِ تو در گلشنِ فردوسِ عِذار |  |
| কি সেটা? এক ময়ূর, যা নাঈমের বাগিচাতে পড়েছে। | چیست؟ طاووس که در باغِ نعیم افتادست |  |
| তোমার মুখের কামনায়, ও আমার জানের দোসর, | دلِ من در هوسِ رویِ تو ای مونس جان |  |
| দিল আমার পথের ধুলা, যা নসিমের হাতে পড়েছে। | خاکِ راهیست که در دستِ نسیم افتادست |  |
| ধুলার মতো এই মাটির শরীর পারে না যে উঠতে | همچو گَرد این تنِ خاکی نتوانَد برخاست |  |
| তোমার গলি থেকে, কারণ বড় বিষম ঘাতে পড়েছে। | از سرِ کویِ تو زان رو که عظیم افتادست |  |
| আমার কায়ায় তোমার দেহের ছায়াটি, ও ঈসা-দম, | سایهٔ قَدِّ تو بر قالبم ای عیسی دم |  |
| রুহের ছবি, যা জীর্ণ হাড়ের ওই সারিতে পড়েছে। | عکسِ روحیست که بر عَظمِ رَمیم افتادست |  |
| তোমার ঠোঁটের স্মরণে যার কাবা ছাড়া ছিল না ঠাঁই, | آن که جز کعبه مُقامش نَبُد از یادِ لبت |  |
| দেখলাম সে এখন শুঁড়িখানার দরজাতে পড়েছে। | بر درِ میکده دیدم که مُقیم افتادست |  |
| হারানো হাফিজের সাথে তোমার দুখের, প্রিয় ইয়ার, | حافظِ گمشده را با غمت ای یارِ عزیز |  |
| এমন মিলন, যা সেই আদিকালের ওয়াদাতে পড়েছে। | اتحادیست که در عهدِ قدیم افتادست |  |
