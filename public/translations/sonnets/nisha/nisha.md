---
title: Sonnets · 116–154
type: sonnet
lang: en
---

| বাংলা | ইংলিশ | # |
| :-- | :-- | --: |
| সত্য মনের মিলনে আমি যেন না দিই সায় | Let me not to the marriage of true minds | 116 |
| কোনো বাধায়। সেই প্রেম তো প্রেমই নয় আসলে | Admit impediments. Love is not love |  |
| যা বদলে যায় যখনই বদল দেখতে পায়, | Which alters when it alteration finds, |  |
| অথবা সরানেওয়ালার সাথে নিজেই সরে চলে: | Or bends with the remover to remove: |  |
| | | |
| আরে না! এ তো এক চির-অবিচল নিশানা স্থির | O no! it is an ever-fixed mark |  |
| যে তুফান দেখে, তবু কখনো হয় না কম্পিত; | That looks on tempests and is never shaken; |  |
| এ হলো সেই ধ্রুবতারা প্রতি দিশাহারা তরীর, | It is the star to every wandering bark, |  |
| যার দাম অজানা, যদিও উচ্চতা পরিমিত। | Whose worth's unknown, although his height be taken. |  |
| | | |
| প্রেম কালের ভাঁড় নয়, যদিও রাঙা ঠোঁট-গাল | Love's not Time's fool, though rosy lips and cheeks |  |
| তার বাঁকা কাস্তের সীমানার মাঝে এসে যায়; | Within his bending sickle's compass come: |  |
| প্রেম বদলায় না তার ঘণ্টা-হপ্তার তাল, | Love alters not with his brief hours and weeks, |  |
| বরং সে টিকে থাকে কিয়ামতেরও কিনারায়। | But bears it out even to the edge of doom. |  |
| | | |
| এ যদি হয় ভুল, ও প্রমাণিত আমার উপর, | If this be error and upon me proved, |  |
| তবে আমি লিখিনি কভু, ভালোবাসেনি কোনো নর। | I never writ, nor no man ever loved. |  |
| | | |
| এভাবে আমায় দোষ দাও: করেছি যে কৃপণতা | Accuse me thus: that I have scanted all | 117 |
| সবকিছুতে, যেখানে তোমার ঋণ শোধার দায়, | Wherein I should your great deserts repay, |  |
| ভুলেছি তোমার প্রিয়তম প্রেমকে ডাকার কথা, | Forgot upon your dearest love to call, |  |
| যার সাথে সব বাঁধন আমাকে রোজ বেঁধে যায়; | Whereto all bonds do tie me day by day; |  |
| | | |
| যে অচেনা সব মনের সাথেই কাটিয়েছি বেশ, | That I have frequent been with unknown minds |  |
| দিয়েছি কালকে তোমার দামেই কেনা অধিকার, | And given to time your own dear-purchased right |  |
| যে সব বাতাসে তুলেছি পাল আমি নির্বিশেষ | That I have hoisted sail to all the winds |  |
| যা আমাকে নেবে তোমার দৃষ্টির বহু ওপার। | Which should transport me farthest from your sight. |  |
| | | |
| লিখে রাখো আমার জেদ আর ভুল সব খাতায় | Book both my wilfulness and errors down |  |
| আর খাঁটি প্রমাণের উপর জমাও অনুমান; | And on just proof surmise accumulate; |  |
| আমাকে এনে রাখো তোমার ভ্রুকুটির পাল্লায়, | Bring me within the level of your frown, |  |
| কিন্তু জাগা ঘৃণায় আমার দিকে ছুঁড়ো না বাণ; | But shoot not at me in your waken'd hate; |  |
| | | |
| আমার আর্জি বলে: চেয়েছি করতে প্রমাণিত | Since my appeal says I did strive to prove |  |
| তোমার প্রেম কতটা অটল, কত পুণ্যে স্থিত। | The constancy and virtue of your love. |  |
| | | |
| যেমন, আমাদের খিদেটাকে আরো চাঙা করতে, | Like as, to make our appetites more keen, | 118 |
| ঝাঁঝালো মশলার মিশেলে আমরা জিভ খোঁচাই, | With eager compounds we our palate urge, |  |
| যেমন, অদৃশ্য অসুখ যেন না পারে ধরতে, | As, to prevent our maladies unseen, |  |
| রোগ এড়াতেই রোগী হই যখন জোলাপ খাই; | We sicken to shun sickness when we purge, |  |
| | | |
| তেমনি, তোমার কভু-না-একঘেয়ে মধুতে ভরা, | Even so, being tuff of your ne'er-cloying sweetness, |  |
| তিক্ত চাটনিতেই সাজালাম আমার আহার, | To bitter sauces did I frame my feeding |  |
| আর, সুখে কাতর হয়ে, ভাবলাম এ ঠিক ধারা— | And, sick of welfare, found a kind of meetness |  |
| প্রকৃত প্রয়োজন ছাড়াই ব্যাধিতে পড়া আমার। | To be diseased ere that there was true needing. |  |
| | | |
| তাই প্রেমের এই কৌশল, আগেভাগে ঠেকাতে | Thus policy in love, to anticipate |  |
| যে অসুখ ছিল না, তা হলো নিশ্চিত অপরাধ | The ills that were not, grew to faults assured |  |
| আর সুস্থ দশাকে এনে দিল ওষুধের হাতে | And brought to medicine a healthful state |  |
| যা, ভালোয় ফেঁপে, মন্দেতে চাইত সারার সাধ: | Which, rank of goodness, would by ill be cured: |  |
| | | |
| তবে এ থেকে শিখি, আর জানি এই শিক্ষা খাঁটি: | But thence I learn, and find the lesson true, |  |
| যে তোমার রোগে পড়ে, ওষুধ তার বিষের বাটি। | Drugs poison him that so fell sick of you. |  |
| | | |
| কী সাইরেন-অশ্রুর শরবত করেছি পান, | What potions have I drunk of Siren tears, | 119 |
| নরকের মতোই নোংরা ভাঁটিতে চোলাই করা, | Distill'd from limbecks foul as hell within, |  |
| ভয়কে আশায় আর আশাকে ভয়েতে করে দান, | Applying fears to hopes and hopes to fears, |  |
| যখন দেখলাম জিতছি তখনই গেছি হারা! | Still losing when I saw myself to win! |  |
| | | |
| কত হীন ভুলই করেছে আমার হৃদয়-মন, | What wretched errors hath my heart committed, |  |
| যখন সে ভেবেছে এত সুখী ছিল না কোনোদিন! | Whilst it hath thought itself so blessed never! |  |
| কক্ষ ছেড়ে কেমন ছিটকে গেছে এই নয়ন | How have mine eyes out of their spheres been fitted |  |
| এই পাগল-করা জ্বরের ঘোরে হয়ে দিশাহীন! | In the distraction of this madding fever! |  |
| | | |
| আহা মন্দের মুনাফা! এখন বুঝি তা সত্যি | O benefit of ill! now I find true |  |
| যে ভালো মন্দেরই গুণে হয় আরো ভালোতর; | That better is by evil still made better; |  |
| আর ভাঙা প্রেম, যদি নতুন করে গড়ে ভিত্তি, | And ruin'd love, when it is built anew, |  |
| আগের চেয়ে রূপসী, দৃঢ়, অনেক বৃহত্তর। | Grows fairer than at first, more strong, far greater. |  |
| | | |
| তাই বকা খেয়ে আমি ফিরি আমার সুখের কাছে, | So I return rebuked to my content |  |
| আর খরচের তিনগুণ লাভ মন্দেই আছে। | And gain by ill thrice more than I have spent. |  |
| | | |
| তুমি নিষ্ঠুর ছিলে আগে, তা আজ আমার সখা, | That you were once unkind befriends me now, | 120 |
| আর তখন যে ব্যথার সাথে হয়েছে সাক্ষাৎ, | And for that sorrow which I then did feel |  |
| তাতে নিজ অপরাধের ভারে মাথা নুইয়ে রাখা | Needs must I under my transgression bow, |  |
| দায়, যদি না স্নায়ু পিতল কি পিটানো ইস্পাত। | Unless my nerves were brass or hammer'd steel. |  |
| | | |
| আমার নিষ্ঠুরতা যদি তোমাকে করে কাতর | For if you were by my unkindness shaken |  |
| যেমন আমি তোমারটায়, সয়েছ নরক-কাল, | As I by yours, you've pass'd a hell of time, |  |
| আর আমি, জালিম, নিইনি এতটুকু অবসর | And I, a tyrant, have no leisure taken |  |
| মাপতে, তোমার অপরাধে কী ছিল আমার হাল। | To weigh how once I suffered in your crime. |  |
| | | |
| আহা, আমাদের দুখের রাত যদি মনে করাত | O, that our night of woe might have remember'd |  |
| গভীরতম বোধকে, খাঁটি দুঃখ কেমন বাজে, | My deepest sense, how hard true sorrow hits, |  |
| তোমাকে, তুমি যেমন আমাকে, দিতাম সওগাত | And soon to you, as you to me, then tender'd |  |
| সেই বিনীত মলম যা আহত বুকেরই কাজে! | The humble slave which wounded bosoms fits! |  |
| | | |
| কিন্তু তোমার পাপ এখন হলো মুক্তিপণ; | But that your trespass now becomes a fee; |  |
| আমারটা তোমার পণ, তোমারটা আমার পণ। | Mine ransoms yours, and yours must ransom me. |  |
| | | |
| খারাপ হওয়া ভালো খারাপ খ্যাতি পাওয়ার থেকে, | Tis better to be vile than vile esteemed, | 121 |
| যদি না হওয়াকে শুনতে হয় হওয়ার অভিযোগ, | When not to be receives reproach of being, |  |
| যদি না পাই পাওনা সুখ, সেরকম ভাবে যাকে | And the just pleasure lost, which is so deemed |  |
| আমাদের অনুভূতি না বরং অন্যদের চোখ। | Not by our feeling but by others' seeing. |  |
| | | |
| কেন অন্যের পরকীয় ভণ্ড চোখ সদাই | For why should others’ false adulterate eyes |  |
| আমার কামনাকাতর রক্তকে দেবে আদাব? | Give salutation to my sportive blood? |  |
| আমার দুর্বলতায় কেন আরো দুর্বলের স্পাই, | Or on my frailties why are frailer spies, |  |
| যাদের উইলে আমি যা ভালো ভাবি তাই খারাপ? | Which in their wills count bad what I think good? |  |
| | | |
| না, আমি যা আমি তাই, অতএব যারা করে তাক | No, I am that I am, and they that level |  |
| আমার কামের দিকে তারা নিজেরই গায়ে বিঁধায়। | At my abuses reckon up their own. |  |
| হয়তো আমি সোজা, ওদের ভিতরেই সব বাঁক; | I may be straight, though they themselves be bevel; |  |
| আমার কর্ম দেখাতে পারে না ওরা নোংরা চিন্তায়, | By their rank thoughts my deeds must not be shown, |  |
| | | |
| যদি না তারা এই সাধারণ কুৎসিত কথা মানে: | Unless this general evil they maintain: |  |
| সব মানুষ খারাপ, তাদের খারাপের শাসনে। | All men are bad and in their badness reign. |  |
| | | |
| তোমার দান, তোমার খাতা, আমার মগজেই পাবে | Thy gift, thy tables, are within my brain | 122 |
| বহু দিন টিকে থাকা স্মৃতির অক্ষরে লিখিত, | Full character'd with lasting memory, |  |
| যা সেই সব অলস তালিকার উপরে থেকে যাবে | Which shall above that idle rank remain |  |
| সব সময় ছাড়িয়ে, এমনকি চিরকাল পর্যন্ত, | Beyond all date, even to eternity; |  |
| | | |
| অথবা অন্তত যত দিন এই মগজ আর হার্ট | Or at the least, so long as brain and heart |  |
| প্রকৃতির স্বভাবে ক্ষমতা পাবে বেঁচে থাকার; | Have faculty by nature to subsist; |  |
| যতদিন না তারা বিস্মৃতির ধ্বংসে তোমার পার্ট | Till each to razed oblivion yield his part |  |
| তাদের মুছে, হারাতে পারবে না স্মৃতিলিপি তোমার। | Of thee, thy record never can be miss'd. |  |
| | | |
| ঐ করুণ স্মারক পারত না এত কিছু নিতে, | That poor retention could not so much hold, |  |
| আর হিসাব লাগে না তোমার প্রিয় প্রেম মাপায়, | Nor need I tallies thy dear love to score; |  |
| তাই আমার সাহস হয়েছিল খাতা দিয়ে দিতে, | Therefore to give them from me was I bold, |  |
| বিশ্বাস করতে সেই খাতা যে তোমাকে বেশি পায়: | To trust those tables that receive thee more: |  |
| | | |
| তোমার স্মৃতির জন্য বাড়তি সহায় রাখা মানে | To keep an adjunct to remember thee |  |
| শুধু ভুলে যাওয়ার সুযোগ আমদানি করা মনে। | Were to import forgetfulness in me. |  |
| | | |
| না, সময়, গর্ব করে বলবে না আমি বদলাই: | No, Time, thou shalt not boast that I do change! | 123 |
| তোমার যেসব পিরামিড পায় নতুন দাপট | Thy pyramids built up with newer might |  |
| সেসব আমার কাছে অদ্ভুত না, নতুনত্ব নাই; | To me are nothing novel, nothing strange, |  |
| তারা কেবল আগের দৃশ্যের নতুন কাপড়। | They are but dressings of a former sight. |  |
| | | |
| আমাদের আয়ু কম, তারিফ করি সেজন্যই | Our dates are brief, and therefore we admire |  |
| পুরাতন যাই তুমি চাপাও আমাদের উপর, | What thou dost foist upon us that is old, |  |
| বরং আমাদের কামনায় জন্মাই সবই, | And rather make them born to our desire |  |
| তাও ভাবি না আগেই শুনেছি এই কথার বহর। | Than think that we before have heard them told. |  |
| | | |
| তোমার খতিয়ান বা তুমি কাউকেই আমি মানি না, | Thy registers and thee I both defy, |  |
| অতীত বর্তমান কিছুতেই নেই বিস্ময়; | Not wondering at the present nor the past; |  |
| আমরা যা দেখি ও তোমার সব নথি করে ছলনা, | For thy records and what we see doth lie, |  |
| তোমার নিরন্তর তাড়ায় সব ছোট বড় হয়। | Made more or less by thy continual haste. |  |
| | | |
| এই শপথ করছি, এবং এই হবে সব ক্ষণে: | This I do vow, and this shall ever be: |  |
| তোমার কাস্তে ও তুমি সত্ত্বেও থাকব সত্য মনে। | I will be true, despite thy scythe and thee. |  |
| | | |
| আমার প্রিয় প্রেম পরিস্থিতির পুত্র হলে | If my dear love were but the child of state, | 124 |
| হয়তো নিয়তির জারজের মতো হতো ত্যাজ্য, | It might for Fortune's bastard be unfathered, |  |
| সময়ের ভালোবাসা বা সময়ের ঘৃণার ফলে, | As subject to Time's love or to Time's hate, |  |
| ফুলের সাথে ফুল, আগাছায় আগাছার বর্জ্য। | Weeds among weeds or flowers with flowers gathered. |  |
| | | |
| না, তার নির্মাণ হয়নি কোনো দৈবের দানে; | No, it was builded far from accident; |  |

| যেমন তোমার মুখে দেয় শোকাতুর দুই চোখ। | As those two mourning eyes become thy face. |  |
| ও, তবে তাই উচিত যাতে মানায় তোমার হার্ট | O, let it then as well beseem thy heart |  |
| আমার শোকে, কারণ তোমায় সুন্দর করে শোক, | To mourn for me, since mourning doth thee grace, |  |
| করুণাও সে পোশাক পাক যা পায় প্রত্যেক পার্ট। | And suit thy pity like in every part. |  |
| | | |
| তখন শপথ করব যে বিউটি নিজেই কালো, | Then will I swear beauty herself is black, |  |
| আর সবাই বিশ্রী যাদের নেই তোমার আলো। | And all they foul that thy complexion lack. |  |
| | | |
| সে দিলকে অভিশাপ যে আনে আমার দিলে কান্না | Beshrew that heart that makes my heart to groan | 133 |
| আমি ও আমার বন্ধুকে দেয়া গভীর আঘাতের! | For that deep wound it gives my friend and me! |  |
| কেবল আমাকে যন্ত্রণা দেয়া কি যথেষ্ট না, | Is't not enough to torture me alone, |  |
| আমার মিষ্টি বন্ধুও কেন হবে দাস দাসত্বের? | But slave to slavery my sweet’st friend must be? |  |
| | | |
| তোমার নির্দয় চোখ আমাকে নেয় আমার থেকে, | Me from myself thy cruel eye hath taken, |  |
| আর আমার দ্বিতীয় আত্মাকে ঘিরেছ আরো বেশি। | And my next self thou harder hast engrossed. |  |
| সে, আমি নিজে, আর তুমি সবাই ছেড়েছে আমাকে— | Of him, myself, and thee I am forsaken— |  |
| তিন বার তিন গুণ এ যন্ত্রণায় আমি ফাঁসি। | A torment thrice threefold thus to be crossed. |  |
| | | |
| বন্দি করো আমার দিল তোমার স্টিলের জেলে, | Prison my heart in thy steel bosom’s ward, |  |
| আমার দুস্থ দিল হোক বন্ধুর দিলের জামিন; | But then my friend’s heart let my poor heart bail; |  |
| যে আমায় রাখে সে দারোয়ান পাক আমার দিলে; | Whoe’er keeps me, let my heart be his guard; |  |
| তবে আমার জেলে তুমি হতে পারবে না কঠিন। | Thou canst not then use rigour in my jail. |  |
| | | |
| তবুও তুমি হবে; কারণ আমি তোমাতে বদ্ধ, | And yet thou wilt; for I, being pent in thee, |  |
| তোমার হতে বাধ্য, আমার সব কিছু সুদ্ধ। | Perforce am thine, and all that is in me. |  |
| | | |
| সুতরাং আমি করলাম স্বীকার যে সে তোমার, | So now I have confessed that he is thine, | 134 |
| এবং নিজেকে বন্ধক দিলাম তোমার উইলে, | And I my self am mortgaged to thy will, |  |
| আমি নিজেকে খোয়াবো, যাতে সে অন্যটা আমার | Myself I'll forfeit, so that other mine |  |
| তুমি ফিরিয়ে দাও আর শান্তি পাই তাকে পেলে। | Thou wilt restore to be my comfort still: |  |
| | | |
| কিন্তু তুমি দেবে না, সেও চায় না মুক্তি পেতে, | But thou wilt not, nor he will not be free, |  |
| কারণ তুমি অনেক লোভী, আর সে হৃদয়বান। | For thou art covetous, and he is kind. |  |
| সেও লিখতে শিখেছে আমার জামিনদার হতে | He learned but surety-like to write for me |  |
| সেই চুক্তির অধীনে যা তাকেও বাঁধে সমান। | Under that bond that him as fast doth bind. |  |
| | | |
| সৌন্দর্যের দলিল তোমার তুমি নিয়ে নেবে, | The statute of thy beauty thou wilt take, |  |
| তুমি তো সুদখোর, যে সব কিছু লাগায় ইউজে, | Thou usurer, that put'st forth all to use, |  |
| আমার জন্য ঋণী বন্ধুর বিরুদ্ধে মামলা দেবে; | And sue a friend came debtor for my sake; |  |
| তাই তাকে হারাই আমার নির্দয় এবিউজে। | So him I lose through my unkind abuse. |  |
| | | |
| হারিয়েছি তাকে; আমাকে আর তাকে পেয়েছ তুমি; | Him have I lost; thou hast both him and me; |  |
| সব ভর্তি করে শোধ দেয় সে, তাও মুক্ত না আমি। | He pays the whole, and yet am I not free. |  |
| | | |
| সবার থাকুক ইচ্ছা, তোমার আছে তোমার উইল, | Whoever hath her wish, thou hast thy Will, | 135 |
| এবং উইলের উপরে উইল, সব থেকে বড়; | And Will to boot, and Will in over-plus; |  |
| আমি যথেষ্ট যে এত বেশি চাই তোমার মিল, | More than enough am I that vexed thee still, |  |
| তোমার মিষ্টি ইচ্ছায় এভাবে যোগ করতে আরো। | To thy sweet will making addition thus. |  |
| | | |
| তবে তুমি, যার ইচ্ছা এত বড় আর বিস্তৃত, | Wilt thou, whose will is large and spacious, |  |
| একবারও তোমার ইচ্ছায় আমারটা লুকাবে না? | Not once vouchsafe to hide my will in thine? |  |
| অন্যদের ইচ্ছা হতে হবে ঠিক আর নিবেদিত | Shall will in others seem right gracious, |  |
| যেখানে আমার ইচ্ছা ভালো স্বীকৃতি পাবে না? | And in my will no fair acceptance shine? |  |
| | | |
| সাগর সম্পূর্ণ পানি, তবু তো পায় বৃষ্টির মিল, | The sea, all water, yet receives rain still, |  |
| বার বার বেশি বেশি পানিতে তার ভাঁড়ার ভরে; | And in abundance addeth to his store; |  |
| তুমি উইলের খনি, নিক তোমার এত উইল | So thou, being rich in Will, add to thy Will |  |
| আমার একটা ইচ্ছা, তোমার ইচ্ছা যাতে আরো বাড়ে। | One will of mine, to make thy large will more. |  |
| | | |
| নির্মমতায় খুন করো না কোনো প্রার্থীর দিল; | Let no unkind, no fair beseechers kill; |  |
| শুধু এক কথা ভাবো, আমায় দেখাবে যে উইল। | Think all but one, and me in that one Will. |  |
| | | |
| যদি আমি কাছে গেলে তোমাকে তোমার আত্মা বকে, | If thy soul check thee that I come so near, | 136 |
| অন্ধ আত্মাকে দিব্যি দিয়ে বলো আমি তোমার উইল, | Swear to thy blind soul that I was thy Will, |  |
| আর তোমার আত্মা জানে ইচ্ছা সেখানে থাকে; | And will, thy soul knows, is admitted there; |  |
| প্রেমের জন্য পূরণ ক’রো, মিষ্টি, আমার আপিল। | Thus far for love my love-suit, sweet, fulfil. |  |
| | | |
| উইল ভর্তি করে দেবে তোমার প্রেমের দেরাজে, | Will will fulfil the treasure of thy love, |  |
| হ্যাঁ, তা ইচ্ছায় পূর্ণ করো, আমারো এক ইচ্ছা তাতে। | Ay, fill it full with wills, and my will one. |  |
| বিশাল সব ব্যাপারে প্রমাণ পাওয়া যায় সহজে | In things of great receipt with ease we prove |  |
| এক নাম্বারের মধ্যে কেউ পারে না গণ্য হতে। | Among a number one is reckoned none. |  |
| | | |
| তবে আমাকে অগণিত নাম্বারে বিলীন হতে দাও, | Then in the number let me pass untold, |  |
| যদিও নিব তোমার সঞ্চয়ী হিসাবের পিছু; | Though in thy store’s account I one must be; |  |
| কিছু-না আমাকে ধরো, যদি এই ধরে সুখ পাও | For nothing hold me, so it please thee hold |  |
| যে কিছু-না আমিই তোমার কাছে, মিষ্টি, কিছু। | That nothing me a something, sweet, to thee. |  |
| | | |
| আমার নাম তোমার প্রেম করো, দিয়ে দাও দিল, | Make but my name thy love, and love that still, |  |
| তখন ভালোবাসবে কারণ আমার নাম উইল। | And then thou love’st me for my name is Will. |  |
| | | |
| অন্ধ বোকা প্রেম তুমি কি করো আমার নয়নে | Thou blind fool love, what dost thou to mine eyes | 137 |
| যে তারা লক্ষ করে দেখে না যা তারা দেখে? | That they behold and see not what they see? |  |
| তারা জানে বিউটি কি, দেখে তার বাস কোনখানে, | They know what beauty is, see where it lies, |  |
| তবু সবচেয়ে ভালো ভাবে সবচেয়ে খারাপকে। | Yet what the best is take the worst to be. |  |
| | | |
| যদি অতিপাক্ষিক নজর কলুষিত করে চোখ | If eyes corrupt by over-partial looks |  |
| সেই বন্দরে নোঙ্গর ফেলো যেখানে সবাই চড়ে, | Be anchored in the bay where all men ride, |  |
| চোখের মিথ্যা হাপরে পিটিয়ে কেন বানাও হুক | Why of eyes’ falsehood hast thou forged hooks |  |
| যার সাথে আমার হৃদয়ের বিচার বাঁধা পড়ে? | Whereto the judgment of my heart is tied? |  |
| | | |
| আমার হার্ট কেন তাকে প্রাইভেট প্লট ভাববে | Why should my heart think that a several plot |  |
| যা দিল জানে আসলে সারা দুনিয়ার খেলাঘর?— | Which my heart knows the wide world’s common place?— |  |
| বা কেন আমার চোখ তাকে দেখে তা নয় বলবে, | Or mine eyes, seeing this, say this is not, |  |
| সুন্দর সত্য বসাতে এত বিশ্রী মুখের উপর? | To put fair truth upon so foul a face? |  |
| | | |
| ঠিক কাজে সত্যি ভুল করেছে আমার চোখ দিল, | In things right true my heart and eyes have erred, |  |
| তাই এখন হয়েছে এই মিথ্যা প্লেগের শামিল। | And to this false plague are they now transferred. |  |
| | | |
| আমার প্রিয়া যখন বলে সে সত্য দিয়ে গড়া, | When my love swears that she is made of truth, | 138 |
| বিশ্বাস করি তাকে, যদিও জানি মিথ্যা বলে, | I do believe her though I know she lies, |  |
| যাতে সে মনে করে আমি অশিক্ষিত এক ছোঁড়া, | That she might think me some untutored youth, |  |
| অজ্ঞ দুনিয়ার যত মিথ্যা কৌশলে ছলে। | Unlearned in the world's false subtleties. |  |
| | | |
| এভাবে বৃথাই ভেবে যে সে আমায় ভাবে তরুণ, | Thus vainly thinking that she thinks me young, |  |
| যদিও সে জানে পেরিয়ে গেছে আমার সেরা কাল, | Although she knows my days are past the best, |  |
| সরলভাবে মানি তার মিথ্যুক জিভের গুণ: | Simply I credit her false-speaking tongue: |  |
| দুই দিকে এভাবে সরল সত্য হয় নাকাল: | On both sides thus is simple truth suppressed: |  |
| | | |
| কিন্তু কেন সে বলে না যে সে করছে অন্যায়? | But wherefore says she not she is unjust? |  |
| আর কেন আমি বলি না যে আমি হয়ে গেছি বুড়ো? | And wherefore say not I that I am old? |  |
| ও! প্রেমের সেরা সাজটি আস্থার ভঙ্গিমায়, | O! love's best habit is in seeming trust, |  |
| প্রেমে বয়স চায় না কেউ গুনুক বছর পুরো: | And age in love, loves not to have years told: |  |
| | | |
| তাই আমি শুই তার সাথে, আর সে আমার সাথে, | Therefore I lie with her, and she with me, |  |
| দোষে আমরা মিথ্যায় তোষামোদ পাই যে তাতে। | And in our faults by lies we flattered be. |  |
| | | |
| ও! ডেকো না আমায় সেই অন্যায় সমর্থনে | O! call not me to justify the wrong | 139 |
| যা তোমার নিষ্ঠুরতা চাপায় আমার হার্টে; | That thy unkindness lays upon my heart; |  |
| চোখে আঘাত ক’রো না, করো তোমার জিভের বাণে: | Wound me not with thine eye but with thy tongue: |  |
| শক্তির সাথে শক্তি খাটাও, মেরো না আর্টে। | Use power with power, and slay me not by art. |  |
| | | |
| বলো অন্যখানে প্রেম করো; কিন্তু দৃষ্টিতে, | Tell me thou lov'st elsewhere; but in my sight, |  |
| প্রিয় হার্ট, বিরত থাকো চোখ সরিয়ে তাকাতে: | Dear heart, forbear to glance thine eye aside: |  |
| ছলের আঘাত কেন, যখন তোমার শক্তিতে | What need'st thou wound with cunning when thy might |  |
| তুমি এতই বড়, আমার ঢাল পারে না ঠেকাতে? | Is more than my o'erpressed defence can bide? |  |
| | | |
| আমি তোমায় মাফ করি: ‘আহা! প্রিয়া ভালোই জানে | Let me excuse thee: ‘Ah! my love well knows |  |
| তার মিষ্টি চাহনি হয়েছে আমার দুশমন, | Her pretty looks have been mine enemies, |  |
| তাই মুখ থেকে শত্রুকে ফেরায় অন্যখানে, | And therefore from my face she turns my foes, |  |
| যাতে অন্যখানে করে তারা আঘাত বর্ষণ।’ | That they elsewhere might dart their injuries.’ |  |
| | | |
| তবু এমনটা ক’রো না; যেহেতু আমি প্রায় মৃত, | Yet do not so; but since I am near slain, |  |
| চাহনিতে মারো সোজা, যন্ত্রণা করো দূরীভূত। | Kill me outright with looks, and rid my pain. |  |
| | | |
| যত নিষ্ঠুর তত বিজ্ঞ হও; চাপ দিও না | Be wise as thou art cruel; do not press | 140 |
| আমার বোবা ধৈর্যটাকে বেশি অবজ্ঞায়; | My tongue-tied patience with too much disdain; |  |
| পাছে দুঃখ দেয় কথা, সে কথা করে বর্ণনা | Lest sorrow lend me words, and words express |  |
| আমার দয়া-না-পাওয়া ব্যথার ধরনটা ভাষায়। | The manner of my pity-wanting pain. |  |
| | | |
| বুদ্ধি শেখাতে পারলে তোমায় ভালো হতো আরো, | If I might teach thee wit, better it were, |  |
| ভালো না বাসলেও, প্রেম, অন্তত তাই শোনাতে; | Though not to love, yet, love to tell me so; |  |
| যেমন খিটখিটে রোগী, মৃত্যু কাছে এলে কারো, | As testy sick men, when their deaths be near, |  |
| ডাক্তার শুধু সুখবর পারে তাদের জানাতে; | No news but health from their physicians know; |  |

| কেন হবে না, প্রেমের চোখ কিভাবে সত্য হবে | How can it, O, how can love’s eye be true, |  |
| যদি কান্না আর দৃষ্টি তাকে এত বেশি ব্যস্ত রাখে? | That is so vexed with watching and with tears? |  |
| যদি আমি ভুল দেখি কি আর আশ্চর্য তবে: | No marvel then though I mistake my view: |  |
| আকাশ পরিষ্কার না হলে সূর্যও কি দেখে? | The sun itself sees not till heaven clears. |  |
| | | |
| চালাক প্রেম, চোখের পানিতে করে রেখেছ বুঁদ | O cunning love, with tears thou keep'st me blind |  |
| যাতে ভালো-দেখা চোখ না পায় নোংরা তোমার খুঁত। | Lest eyes well-seeing thy foul faults should find. |  |
| | | |
| ও নির্দয়, ভালোবাসি না তা বলতে পারো না তুমি | Canst thou, O cruel, say I love thee not | 149 |
| যেখানে আমি নিজের বিরুদ্ধে থাকি তোমার সাথে? | When I against myself with thee partake? |  |
| ভাবি না কি তোমার কথা যখন ভুলে যাই আমি | Do I not think on thee when I forgot |  |
| নিজেকে নিষ্ঠুরভাবে কেবল তোমার স্বার্থে? | Am of my self, all-tyrant, for thy sake? |  |
| | | |
| তোমাকে ঘৃণা করে এমন কাকে আমি বন্ধু ডাকি? | Who hateth thee that I do call my friend? |  |
| দেখলে ভ্রু কুঁচকাও আমি তেলাই কাকে এমন? | On whom frown’st thou that I do fawn upon? |  |
| না, তুমি আমার প্রতি রাগলে ভয়ানকভাবে কি | Nay, if thou lour’st on me, do I not spend |  |
| নিজের উপর প্রতিশোধ নেই না কষ্টে তখন? | Revenge upon myself with present moan? |  |
| | | |
| আমার মাঝে কি যোগ্যতা ভাবতে পারি অতুল | What merit do I in myself respect, |  |
| যার এত গর্ব যে ঘৃণা করে তোমার চাকরি | That is so proud thy service to despise, |  |
| যদি আমার সব ভালো পূজা করে তোমার ভুল | When all my best doth worship thy defect, |  |
| যখন হুকুম করে তোমার দুচোখের চরকি? | Commanded by the motion of thine eyes? |  |
| | | |
| কিন্তু, প্রেম, করো ঘৃণা; এখন তোমার মন জানি। | But, love, hate on; for now I know thy mind. |  |
| তোমাকে যারা দেখে ভালোবাসে, আমার চোখে ছানি। | Those that can see thou lov’st, and I am blind. |  |
| | | |
| ও, কোন শক্তি থেকে পেলে এই প্রবল ক্ষমতা, | O, from what power hast thou this powerful might | 150 |
| অপূর্ণতা দিয়ে আমার এ দিলকে দোলাবার? | With insufficiency my heart to sway? |  |
| যাতে মিথ্যুক বলি আমার চোখের সত্যতা, | To make me give the lie to my true sight, |  |
| শপথ করি যে দিনকে শোভা দেয় না আলো তার? | And swear that brightness doth not grace the day? |  |
| | | |
| কোথা থেকে পেলে তুমি মন্দকে মানায় যে সাজ, | Whence hast thou this becoming of things ill, |  |
| যে তোমার কর্মের নিছক আবর্জনাতেও | That in the very refuse of thy deeds |  |
| আছে এমন জোর, দক্ষতার নিশ্চিত কাজ, | There is such strength and warrantise of skill |  |
| আমার মনে তোমার মন্দ ছাড়ায় সেরাকেও? | That, in my mind thy worst all best exceeds? |  |
| | | |
| কে শিখিয়েছে কিভাবে আরো ভালোবাসাবে তোমায় | Who taught thee how to make me love thee more |  |
| যত বেশি শুনি ও দেখি ঘৃণার ন্যায্য কারণ? | The more I hear and see just cause of hate? |  |
| ও, যদিও ভালোবাসি যা অন্যদের ঘৃণা, হায়, | O, though I love what others do abhor, |  |
| অন্যের সাথে আমার দশা ঘৃণা করা বারণ। | With others thou shouldst not abhor my state. |  |
| | | |
| তোমার অযোগ্যতা যদি ভরায় প্রেমে এ মন, | If thy unworthiness raised love in me, |  |
| তবে আমি যোগ্যতর হতে তোমার প্রিয়জন। | More worthy I to be beloved of thee. |  |
| | | |
| প্রেম খুবই কচি, জানে না সে বিবেক কাকে বলে, | Love is too young to know what conscience is, | 151 |
| তবু কে না জানে, বিবেক জন্মায় প্রেমের থেকে? | Yet who knows not conscience is born of love? |  |
| ও মিষ্টি প্রতারক, আমার দোষ ধ’রো না ছলে, | Then, gentle cheater, urge not my amiss, |  |
| পাছে আমার দোষে দোষী দেখো, প্রিয়, তুমি নিজেকে। | Lest guilty of my faults thy sweet self prove. |  |
| | | |
| কারণ, তুমি আমায় ঠকালে, আমিও তো ঠকাই | For, thou betraying me, I do betray |  |
| আমার সেরা অংশ স্থূল দেহের বেইমানিতে। | My nobler part to my gross body’s treason. |  |
| আমার আত্মা বলে দেহকে যে, সে-ও পারে তাই | My soul doth tell my body that he may |  |
| প্রেমে জিততে; দেহ আর মানে না কোনো যুক্তিতে, | Triumph in love; flesh stays no farther reason, |  |
| | | |
| বরং তোমার নাম শুনে উঠে দেখায় তোমায় | But rising at thy name doth point out thee |  |
| জয়ের পুরস্কার ব’লে। এ গর্বে গর্বিত, | As his triumphant prize. Proud of this pride, |  |
| সে সন্তুষ্ট তোমার গরিব গোলাম হওয়ায়, | He is contented thy poor drudge to be, |  |
| তোমার কাজে দাঁড়াতে, তোমার পাশে হতে পতিত। | To stand in thy affairs, fall by thy side. |  |
| | | |
| একে বিবেকের অভাব ভেবো না যদি আমি বলি | No want of conscience hold it that I call |  |
| তাকে ‘প্রেম’, যার প্রিয় প্রেমে আমি উঠি আর ঢলি। | Her ‘love’ for whose dear love I rise and fall. |  |
| | | |
| তোমায় ভালোবেসে, জানো তো, আমি ভেঙেছি শপথ, | In loving thee thou know’st I am forsworn, | 152 |
| কিন্তু তুমি দুবার ভাঙো, প্রেমের কসম খেয়ে, | But thou art twice forsworn to me love swearing |  |
| কাজে শয্যা-শপথ ভেঙে, ছিঁড়ে আস্থার পথ, | In act thy bed-vow broke, and new faith torn |  |
| নতুন প্রেম পেয়ে নতুন ঘৃণার শপথ নিয়ে। | In vowing new hate after new love bearing. |  |
| | | |
| কিন্তু দুই শপথ ভাঙায় কেন দুষি তোমায়, | But why of two oaths’ breach do I accuse thee, |  |
| যখন ভাঙি বিশটা? আমিই বড় শপথ-চোর, | When I break twenty? I am perjured most, |  |
| সব শপথ শুধু তোমায় এবিউজের উপায়, | For all my vows are oaths but to misuse thee, |  |
| তোমাতে আমার সৎ বিশ্বাস হারিয়েছে জোর। | And all my honest faith in thee is lost. |  |
| | | |
| গভীর কসম খেয়েছি তোমার গভীর দয়ার, | For I have sworn deep oaths of thy deep kindness, |  |
| তোমার প্রেম, তোমার সত্য, তোমার অটলতা, | Oaths of thy love, thy truth, thy constancy, |  |
| তোমায় আলো দিতে চক্ষু দিলাম অন্ধতার, | And to enlighten thee gave eyes to blindness, |  |
| বা চোখ দিয়ে বলালাম, যা দেখে তা মিথ্যা কথা। | Or made them swear against the thing they see. |  |
| | | |
| বলেছি তুমি সুন্দর—চক্ষু আরো মিথ্যুক, | For I have sworn thee fair—more perjured eye |  |
| সত্য-বিপক্ষে নোংরা মিথ্যায় দেয় মুখ। | To swear against the truth so foul a lie. |  |
| | | |
| কিউপিড ঘুমিয়ে পড়েছিল তার মশালের পাশে। | Cupid laid by his brand and fell asleep. | 153 |
| ডায়ানার এক সাথী এই সুযোগ কাজে লাগায়, | A maid of Dian’s this advantage found, |  |
| তার প্রেম-জ্বালানো আগুন তাড়াতাড়ি ডুবায় সে | And his love-kindling fire did quickly steep |  |
| সেখানের সমতলে বয়ে চলা শীতল ঝরনায়, | In a cold valley-fountain of that ground, |  |
| | | |
| যা প্রেমের এ পবিত্র আগুনের থেকে ধারে আনে | Which borrowed from this holy fire of Love |  |
| এক শাশ্বত সজীব তাপ, যাতে না হয় বিলয়, | A dateless lively heat, still to endure, |  |
| আর বানায় এত ফেনার বাথ যা, পুরুষ জানে, | And grew a seething bath which yet men prove |  |
| অপরিচিত সব রোগের চূড়ান্ত নিরাময়। | Against strange maladies a sovereign cure. |  |
| | | |
| আমার মিস্ট্রেসের চোখে নতুন প্রেমের শিখা | But at my mistress’ eye love’s brand new fired, |  |
| পরখ করতে ছেলেটা দেয় আমার বুকে ছুঁয়ে। | The boy for trial needs would touch my breast. |  |
| রোগে কাতর আমি চাই সহযোগী স্নানের দেখা, | I, sick withal, the help of bath desired, |  |
| ও দ্রুত যাই সেখানে অসুস্থ দুখী অতিথি হয়ে, | And thither hied, a sad distempered guest, |  |
| | | |
| ওষুধ পাইনি; আজো সেই স্নান, যা সারাত রোগ, | But found no cure; the bath for my help lies |  |
| কিউপিডের মশাল: আমার মিস্ট্রেসের চোখ। | Where Cupid got new fire: my mistress’ eyes. |  |
| | | |
| ছোট্ট প্রেমের দেবতা শুয়ে ঘুমিয়ে পড়ার পরই, | The little love-god lying once asleep | 154 |
| তার সেই দিলজ্বালানো মশাল রেখে তার সাথে, | Laid by his side his heart-inflaming brand, |  |
| সারা জীবন সতী থাকতে চাওয়া অনেক পরী | Whilst many nymphs that vowed chaste life to keep |  |
| এসেছিল দৌড়িয়ে; কিন্তু নিজের কুমারী হাতে | Came tripping by; but in her maiden hand |  |
| | | |
| আগুনটা নেয় তাদের মধ্যে যে সবচে’ রূপবতী, | The fairest votary took up that fire |  |
| যা গরম সত্য হৃদয়ের বহু বাহিনীর তাতে, | Which many legions of true hearts had warmed, |  |
| সুতরাং সেইখানে তপ্ত তৃষ্ণার সেনাপতি | And so the general of hot desire |  |
| ঘুমাচ্ছিল হাতিয়ার হারিয়ে ভার্জিনের হাতে। | Was sleeping by a virgin hand disarmed. |  |
| | | |
| এ মশাল সে নিভায় পাশের এক ঠাণ্ডা কুয়ায়, | This brand she quenched in a cool well by, |  |
| যা প্রেমের আগুন থেকে নিচ্ছিল অনন্ত হুতাশ, | Which from love’s fire took heat perpetual, |  |
| আর সুস্বাস্থ্যের সহযোগী একটি বাথ বানায় | Growing a bath and healthful remedy |  |
| রোগী পুরুষের জন্য; কিন্তু আমি, মিস্ট্রেসের দাস, | For men diseased; but I, my mistress’ thrall, |  |
| | | |
| সেখানে যাই ওষুধ পেতে; যা এই প্রমাণ করে: | Came there for cure; and this by that I prove: |  |
| প্রেম পানিতে নিভে না, প্রেমের আগুনে পানি পুড়ে। | Love’s fire heats water, water cools not love. |  |
